## 💡 About

This portfolio site is a one‑page (or multi‑section) web application that highlights:

- **My Background:** Education, Certifications, and skills  and also Languages
- **Projects:**  Demos and GitHub links  
- **Resume:** Downloadable PDF version  
- **Contact Form:** Send me a message directly  

It’s fully responsive, mobile‑friendly, and built to be easy to customize and extend.

## 🚢 Deployment

This site is hosted on Vercel. To deploy updates:

1. Commit and push your changes to the `main` branch.
2. In your GitHub repo settings → Pages → choose `main`/`root`.
3. Save. Within a minute, your changes will be live at **https://iam-abir.vercel.app**
